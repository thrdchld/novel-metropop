# MetroPop Agent Rules

Baca `AGENTS.md` di root repo, lalu `engine/README.md` dan `engine/00-workflow.md`.
Gunakan `acuan-bahasa.docx` sebagai acuan utama gaya bahasa, diksi, dan cara bercerita.

Mulai sesi dengan satu pertanyaan: ide baru, project baru, lanjutkan, revisi, atau riset.
Jangan menulis prosa sebelum mode dipilih dan outline disetujui/terkunci.
Target pembaca 13+. Prinsip Pas: teknik/subplot/flashback/scene ikonik opsional.
