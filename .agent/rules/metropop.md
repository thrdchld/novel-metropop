# MetroPop Agent Rules

Baca `AGENTS.md` di root repo, lalu `engine/README.md`, `engine/00-workflow.md`, dan `engine/05-style.md`.
Gunakan `acuan-bahasa.docx` sebagai acuan utama gaya bahasa, diksi, dan cara bercerita.

## Aturan Mutlak Menulis (Non-Negotiable)

1. Mulai sesi dengan satu pertanyaan: ide baru, project baru, lanjutkan, revisi, atau riset.
2. Jangan menulis prosa sebelum mode dipilih dan outline disetujui/terkunci.
3. Wajib membaca `story/<Judul>/` (canon.md, outline.md, ledger.md) sebelum menulis bab.
4. Setiap bab wajib 600–900 kata (target ±750 kata).
5. Dilarang keras memakai em dash (`—`) di seluruh novel.
6. Dilarang memasang quote/epigraph di atas bab.
7. Bebas dari AI slop dan bahasa baku kaku: gunakan gaya percakapan alami perkotaan Indonesia.
8. Jika ada masukan/koreksi baru dari user, catat di `engine/learnings/editor-feedback.md` dan update file engine terkait.
