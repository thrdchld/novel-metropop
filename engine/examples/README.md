# Examples

Contoh di folder ini **orisinal** dan hanya untuk ilustrasi struktur/gaya. Jangan menyalin
kalimat atau adegan ke novel. Gunakan sebagai model, bukan bahan tempel.

| File | Isi |
|---|---|
| `premise-example.md` | 3 opsi premis dengan format lengkap. |
| `outline-example.md` | Satu bab dengan semua kolom outline. |
| `scene-example.md` | Adegan contoh: in medias res, dialog, hook. |
| `hooks.md` | Variasi hook per tipe. |
| `style-before-after.md` | Perbaikan gaya: sebelum/sesudah. |

Aturan:

- Jangan menyalin nama, perusahaan, atau plot contoh ke project baru.
- Contoh boleh dipakai untuk membandingkan ritme.
- Jika user memberi contoh gaya sendiri, itu menang atas contoh di sini.
