# Folder Story

Satu cerita = satu folder, dinamai sesuai judul. Semua `canon.md`, `state.md`, `outline.md`, `ledger.md`, dan naskah bab disimpan di sini.

## Acuan Utama

Seluruh aturan penulisan berada di folder `../engine/` (lihat peta lengkap di `../engine/README.md`) dan acuan gaya bahasa di `../acuan-bahasa.docx`.

## Struktur Folder Cerita

```text
story/
├── universe-registry.md  # Pendaftar semesta terpadu (portofolio, bank premis, roster tokoh, entitas dunia, protokol cameo 3 tingkat)
└── <Judul>/
    ├── canon.md          # Sumber kebenaran: premis (ABCD & 5 slot), penutupan jalan mudah, kerangka plot, planting 2x, cast, aturan dunia
    ├── state.md          # Penjaga kondisi aktif garis depan penulisan (dibaca sebelum & diperbarui sesudah menulis bab)
    ├── outline.md        # Peta 30–40 bab (min 6–8 titik balik, siklus coba-gagal, 18 kolom wajib per bab)
    ├── ledger.md         # Arsip kronologis fakta cerita per bab
    ├── publish-stuff.md  # Paket publikasi: blurb simpel & teasing + sinopsis singkat awal-akhir
    ├── manuscript.md     # Gabungan seluruh bab utuh
    ├── feedback.md       # Catatan feedback pengguna dan tindakan revisi
    └── chapters/
        ├── bab-01.md
        ├── bab-02.md
        └── ...
```

Gunakan template di `../engine/templates/`. Jangan mengarang format baru.
